# AileTakip gerçek sürüm
Bu sürüm Firebase bağlandığında gerçek hesap, aile, davet kodu, izinli konum paylaşımı ve Firestore konum geçmişi kullanır.
Firebase Console'dan Web App oluşturup `app.js` içindeki `firebaseConfig` alanını doldurmalısın. Authentication'da Email/Password'u ve Firestore'u açmalısın.
